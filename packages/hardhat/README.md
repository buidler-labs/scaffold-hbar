# packages/hardhat — cross-chain DCA

Hardhat config, contracts, scripts, and tests for the cross-chain DCA template. Contains contracts for both chains:

- `contracts/hedera/` — `DcaOrchestrator` + `AxelarMessageSender` (Hedera testnet, chain 296)
- `contracts/sepolia/` — `DcaExecutor` + `AxelarMessageReceiver` (Sepolia, chain 11155111)

## Setup

Copy the example env file and fill in the values:

```bash
cp .env.example .env
```

| Variable | Required | Where to get it |
|---|---|---|
| `HEDERA_RPC_URL` | Yes | Pre-filled with the public HashIO endpoint |
| `HEDERA_DEPLOYER_PRIVATE_KEY_ENCRYPTED` | Yes | Set automatically by `yarn account:generate` or `yarn account:import` — do not edit manually |
| `SEPOLIA_RPC_URL` | Yes | [Infura](https://infura.io) or any Sepolia RPC provider |
| `ETH_DEPLOYER_PRIVATE_KEY_ENCRYPTED` | Yes | Set automatically by `yarn account:generate` or `yarn account:import` — do not edit manually |
| `ETHERSCAN_API_KEY` | Verify only | [Etherscan](https://etherscan.io/myapikey) |
| `AXELAR_GATEWAY_HEDERA` | Yes | Pre-filled with Axelar's Hedera testnet gateway |
| `AXELAR_GAS_SERVICE_HEDERA` | Yes | Pre-filled with Axelar's Hedera testnet gas service |
| `AXELAR_GATEWAY_SEPOLIA` | Yes | Pre-filled with Axelar's Sepolia gateway |
| `USDC_ADDRESS` | Yes | Pre-filled with Sepolia USDC |
| `UNISWAP_ROUTER` | Yes | Pre-filled with Uniswap v3 router on Sepolia |
| `ORCHESTRATOR_FUND_AMOUNT` | Optional | Amount of HBAR to send to DcaOrchestrator (default: 10) |
| `FUND_USDC_AMOUNT` | Optional | Amount of USDC to send to DcaExecutor (default: 5) |

## Account setup

Run these once before deploying. Private keys are encrypted and stored in `.env` — never edit the encrypted fields manually.

```bash
yarn account:generate   # Generate a new wallet for Hedera or Sepolia and save the encrypted key to .env
yarn account:import     # Import an existing private key, encrypt it, and save it to .env
yarn account            # Display address, QR code, and balance for configured accounts
yarn account:reveal-pk  # Decrypt and print the plaintext private keys (use with caution)
```

## Compile

```bash
yarn compile          # Compile all contracts
yarn hedera:compile   # Alias — same output as yarn compile
yarn sepolia:compile  # Alias — same output as yarn compile
```

## Deploy

The `deploy` script runs the full 10-step deployment in one shot: compile → deploy Hedera contracts → deploy Sepolia contracts → wire both sides → fund orchestrator and executor → create a DCA plan → verify both chains.

```bash
yarn deploy           # Full end-to-end deployment across both chains, including verification (recommended starting point)
```

You will be prompted for your Etherscan API key if it is not already saved in `.env`. It is written once and skipped on subsequent runs.

After deployment, `packages/nextjs/contracts/deployedContracts.ts` is auto-generated with the latest ABIs and addresses. Do not edit this file manually — it will be overwritten on the next deploy.

For re-running individual steps (e.g. after a partial failure):

```bash
yarn hedera:deploy    # Deploy DcaOrchestrator + AxelarMessageSender to Hedera testnet
yarn sepolia:deploy   # Deploy DcaExecutor + AxelarMessageReceiver to Sepolia
yarn hedera:wire      # Set the Sepolia receiver address on AxelarMessageSender (run after sepolia:deploy)
yarn sepolia:wire     # Set the Hedera sender address on AxelarMessageReceiver (run after hedera:deploy)
```

## Fund and manage

```bash
yarn hedera:fund            # Send HBAR from deployer wallet to DcaOrchestrator
yarn sepolia:fund:usdc      # Send USDC from deployer wallet to DcaExecutor
yarn sepolia:balance:check  # Display ETH, USDC, and WETH balances held by DcaExecutor
```

DCA plan management:

```bash
yarn hedera:plan:create      # Create a new DCA plan on DcaOrchestrator (configure parameters in .env)
yarn hedera:plan:cancel      # Cancel a plan by ID (set CANCEL_PLAN_ID=<id> in .env first)
yarn hedera:plan:reschedule  # Reschedule a plan that failed its initial scheduling attempt
yarn hedera:plan:latest      # Inspect the most recently created plan
```

## Withdraw

```bash
yarn hedera:withdraw:orchestrator  # Withdraw all HBAR from DcaOrchestrator to the owner address
yarn hedera:withdraw:sender        # Withdraw all HBAR from AxelarMessageSender to the owner address
yarn sepolia:withdraw:executor     # Withdraw all ETH and ERC-20 tokens from DcaExecutor
yarn sepolia:withdraw:receiver     # Withdraw all ETH and ERC-20 tokens from AxelarMessageReceiver
```

## Test

```bash
yarn test               # Run all tests
yarn hedera:test        # Run Hedera contract tests only
yarn sepolia:test       # Run Sepolia contract tests only
```

Tests run on the in-process Hardhat network — no `.env` or live RPC required.

## Verify

```bash
yarn hedera:verify    # Verify Hedera contracts on Sourcify (chain 296, no API key needed)
yarn sepolia:verify   # Verify Sepolia contracts on Etherscan (requires ETHERSCAN_API_KEY in .env)
```

## Layout

```

  hedera/           DcaOrchestrator.sol, AxelarMessageSender.sol, interfaces/, test/
  sepolia/          DcaExecutor.sol, AxelarMessageReceiver.sol, interfaces/, test/
scripts/
  hedera/           deploy, wire, fund, plan management, verify, withdraw scripts
  sepolia/          deploy, wire, fund, balance-check, verify, withdraw scripts
  deployAll.ts     full 8-step deployment (both chains)
  generateDeployedContracts.ts  writes packages/nextjs/contracts/deployedContracts.ts
test/
  hedera/           DcaOrchestrator.ts, AxelarMessageSender.ts
  sepolia/          DcaExecutor.ts
config/
  deployed-addresses.example.json  shape reference
  deployed-addresses.json          written at deploy time, gitignored
hardhat.config.ts   networks: hardhat, hederaTestnet, hederaMainnet, ethereumSepolia
```
